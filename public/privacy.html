YOUR RECORDS, YOUR SPACE

개인정보와 데이터 보관

현재 준비 중인 개인용 일기장의 데이터 처리 안내입니다. 학교·학생용 서비스의 최종 개인정보 처리방침을 대신하지 않습니다.

로그인과 저장

Google 로그인은 Firebase Authentication이 처리합니다. 계정 식별자와 Google에서 제공하는 로그인 프로필이 인증에 사용됩니다. 비밀번호를 이 웹앱이 직접 받거나 보관하지 않습니다. 일기의 날짜·제목·내용·기분·태그·소중한 일기 표시·저장 시각은 로그인한 계정별로 Google Cloud Firestore에 저장됩니다.

일기 원문이 Google 클라우드로 전송되며, 종단간 암호화는 제공하지 않습니다. 프로젝트 관리자에게는 관리 권한에 따른 접근 가능성이 있습니다. 다른 이용자가 본인의 일기를 읽거나 수정할 수 없도록 Firebase 보안 규칙을 적용해야 합니다.

이 기기에 남는 정보

이 앱은 일기 원문을 브라우저 영구 저장소에 보관하도록 설정하지 않습니다. 로그인 상태는 브라우저 세션 범위에서 유지됩니다. 공유 컴퓨터에서는 반드시 로그아웃하고 창을 닫으세요. 화면의 내용·다운로드한 백업·운영체제 또는 브라우저가 보관하는 정보까지 지우는 기능은 아닙니다.

내보내기·복원·삭제

백업 기능으로 본인의 기록을 JSON 파일로 내려받을 수 있습니다. 이 파일에는 일기 원문이 포함됩니다. 복원은 선택한 파일을 현재 로그인 계정의 클라우드에 전송하며, 기존 기록은 덮어쓰지 않습니다. 한 번에 최대 200편·5MB까지 복원할 수 있습니다. 기존 로컬 일기장 데이터는 자동 전송하지 않습니다.

저장된 일기는 직접 삭제하기 전까지 보관됩니다. 앱의 삭제 기능은 해당 일기 문서를 삭제하며 되돌리기 기능은 없습니다. 내려받은 백업은 별도로 삭제해야 합니다. 계정 전체 삭제·운영 문의 창구·구체적인 국외 처리 및 보존 정책은 운영 주체가 정한 뒤 일반 공개에 앞서 안내를 보완해야 합니다.

허브와 교사용 도구

허브 시작 화면에는 학생 명부·출결·일기 원문을 포함하지 않습니다. 분석·광고용 SDK는 추가하지 않습니다. GitHub Pages는 화면을 제공하며, 실제 이용 시 GitHub 및 Google의 인프라에서 접속 관련 정보가 처리될 수 있습니다.

기존 교사용 도구는 별도 Apps Script 서비스입니다. 운영 주체·학교 승인·수집 근거·보존기간·학생 및 아동 처리 안내가 확정되기 전에는 실제 학생 자료를 수집하지 마세요.
