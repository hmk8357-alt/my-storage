# 웹앱 허브 배포 설계

2026-11-07. 원본: 교사용 Apps Script 허브, 로컬 ‘오늘의 조각’ 일기장. 원본과 실제 데이터는 변경하지 않는다.

## 제안 구성

- GitHub Pages: 공개 허브 시작 화면과 일기장 정적 화면. 하위 경로 배포를 지원한다.
- 교사용 도구: 기존 Apps Script 인증·Sheets 저장 구조를 유지하고 허브에서 연결한다. 현재 실배포 URL이 없어 설정 전까지 준비 중으로 표시한다.
- 일기장: 새 Firebase 프로젝트의 Google 로그인과 Firestore를 사용한다. 경로는 users/{uid}/entries/{entryId}이며 본인만 접근한다. 로그아웃·계정 변경 시 이전 일기와 입력을 화면에서 지운다.
- 로컬 SQLite 및 JSON 백업은 업로드하거나 자동 이전하지 않는다. 사용자가 직접 선택하는 복원만 제공한다.
- 일기 원문은 Firestore에 저장되며 종단간 암호화는 제공하지 않는다. 서버 측 규칙으로 비로그인·다른 계정 접근, 허용하지 않은 필드·타입·길이를 거부한다.
- Firebase 미설정 또는 접근 실패 시 저장 성공으로 표시하지 않는다. 실제 계정의 로그인·저장·다른 계정 접근 차단을 배포 후 확인한다.
- 공개 저장소에는 검토한 소스만 포함한다. 인증 토큰, 서비스 계정 키, SQLite, 학생 명부, 백업, 환경 도구와 로컬 설정은 제외한다.

## 대안

기존 GAS 앱을 Pages에 그대로 복사하면 서버 호출이 동작하지 않는다. 교사용 세 도구까지 Firebase로 이전하면 승인 교사·학생 코드·출결 권한 구조 전체를 다시 구현해야 하므로 이번 일기장 백엔드 작업보다 범위가 커진다. 따라서 공개 시작 화면 + 기존 교사 도구 연결 + Firebase 일기장을 제안한다.

## 진행 결과

사용자가 구성을 승인했고 Firebase 새 프로젝트와 Google 로그인 설정을 배포했다. 사용자 승인에 따라 서울 Standard 데이터베이스를 사용한다. GitHub 저장소는 사용자가 만든 `hmk8357-alt/my-storage`를 사용했고 Pages 배포와 실제 로그인·저장 확인을 마쳤다. 학생용 기존 허브는 원본 문서상 운영 주체·연락처·보존기간·아동 처리 기준이 미확정이며 실제 학생 자료 수집을 시작할 준비가 끝난 상태가 아니다.
